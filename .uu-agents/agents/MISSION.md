# Mission

UU libraries provide small, opinionated layers over native platform APIs.

The goal is to make common project behavior consistent, safe, readable, and reusable across UU projects while preserving the strengths and expectations of the underlying platform. UU libraries should feel like natural extensions of their platform, not replacements for it.

## What UU Code Should Optimize For

1. Correctness and safety
2. Native platform behavior
3. Clear public contracts
4. Readability and simplicity
5. Reuse where behavior or policy is truly shared
6. Testability
7. Performance when justified

## What UU Libraries Are Not

UU libraries are not intended to replace native SDKs, hide platform concepts, wrap every platform API, become framework-style architectures, or make simple platform behavior look proprietary.
